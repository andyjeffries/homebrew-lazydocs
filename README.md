# Homebrew Tap for LazyDocs

This is the official Homebrew tap for [LazyDocs](https://github.com/andyjeffries/lazydocs).

## Installation

```bash
brew tap andyjeffries/lazydocs
brew install lazydocs
```

## Updating

```bash
brew update
brew upgrade lazydocs
```

## Uninstalling

```bash
brew uninstall lazydocs
brew untap andyjeffries/lazydocs
```
